# Actual desktop captures

These PNGs were captured from the published self-contained Harbor Avalonia executable (`artifacts/harbor-linux-x64/Harbor.App`, launched directly without the .NET SDK) on an x86-64 Linux cloud machine using Xvfb and Avalonia's X11 backend at 1220×820. They are actual application windows, not mockups or generated artwork.

- `dashboard.png`: genuine first-run empty dashboard.
- `onboarding.png`: real server creation form, upper scroll position.
- `onboarding-eula.png`: real lower form, including the unchecked EULA acceptance control and installation action. The form was scrolled through actual X input.

The Minecraft catalog request returned a proxy HTTP 403 in this environment, shown honestly in the interface. No server definitions, metrics, logs, or EULA acceptance were fabricated for these captures. No server was started. Selected-server overview, real-session console, mods, and backup screenshots require an actual configured installation and explicit EULA acceptance, and remain unverified. These captures do not constitute a Kubuntu/KDE, Wayland, fractional scaling, or live Minecraft integration test.
