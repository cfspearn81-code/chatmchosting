# Harbor Linux development download

Download harbor-linux-x64.tar.gz from this branch and verify it with SHA256SUMS.

Extract and run `harbor-linux-x64/harbor`. This package includes the .NET runtime; native Linux desktop libraries are still required. The source is on branch feature/harbor-kubuntu, commit d9ed3d554bef9f40ffaed03a62292b095e791485.

This development build was built and launched on Debian x86-64 under X11. Kubuntu and live Minecraft/loader validation remain unverified. See the source branch's docs/RELEASE-REPORT.md for limitations. No Minecraft artifacts, worlds or EULA acceptance are bundled.
